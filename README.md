# 🪨 Stone-Paper-Scissors Game

A classic **Stone-Paper-Scissors** web game built from scratch using core front-end web technologies. This project was developed as a hands-on learning exercise to strengthen fundamental concepts in web development and interactive JavaScript programming.

---

## 🚀 Features

* **Interactive Gameplay:** Play against the computer in real-time.
* **Smart Game Logic:** Implements random computer choices and determines winners accurately based on standard rules.
* **Dynamic Score Tracking:** Keeps track of player and computer scores during the session.
* **Clean UI/UX:** Styled using modern CSS for an intuitive and responsive user experience.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and layout of the game interface.
* **CSS3:** Styling, custom design elements, layout alignment, and hover effects.
* **JavaScript (ES6):** DOM manipulation, event listeners, game state logic, and randomized computer moves.

---

## 🎮 How to Play

1. Choose your move by clicking on **Stone**, **Paper**, or **Scissors**.
2. The computer will randomly generate its choice.
3. The winner is determined based on classic rules:
   * **Stone** crushes **Scissors**
   * **Scissors** cuts **Paper**
   * **Paper** wraps **Stone**
4. The scoreboard updates automatically based on the round result.
